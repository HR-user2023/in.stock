# 髮廊點貨本

手機用的髮廊庫存、叫貨、到貨核對小工具。網頁放在 GitHub Pages，資料存在你自己的 Google 試算表。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 網頁本體 |
| `catalog.js` | 廠商價目表（台灣歌薇、威娜、哥德式、萊肯、覺亞、京喚羽、金韓今、好日梓、資生堂，共 1,510 項） |
| `apps-script.gs` | 貼到 Google 試算表的後端程式 |

## 第一次設定（只要做一次）

### 1. 開啟網頁
到 repository 的 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 **main / (root)**，按 Save。
一兩分鐘後網址會是：`https://你的帳號.github.io/salon-stock/`

### 2. 連接 Google 試算表
1. 打開一份 Google 試算表 → **擴充功能 → Apps Script**
2. 把 `apps-script.gs` 的內容全部貼上，取代原本的內容，按儲存
3. 右上 **部署 → 新增部署作業** → 齒輪選 **網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**
4. 按部署，允許權限（出現「Google 尚未驗證」時點 **進階 → 前往（不安全）→ 允許**）
5. 複製「網頁應用程式」網址（`https://script.google.com/.../exec`）

### 3. 把網址貼進網頁
打開網頁 → **更多 → 設定** → 貼上網址 → 按 **連線**。
在設定頁按 **複製員工連結**，傳給員工打開一次，就會連到同一份資料。

## 日常使用

- **庫存**：最上面搜尋產品（`7b`、`tokio`、`洗髮`），點一下看庫存、入庫、盤點、看最近異動；第一次用請按「依品牌入庫／盤點」把現有庫存輸入
- **每日點貨**：今天用掉的產品填數量 → 「扣庫存」，下面列出今天每一筆（時間、經手人）
- **叫貨**：最上面是本月叫貨總額和還沒到貨金額 → 建立叫貨清單（選廠商、叫貨日期、數量，會提醒最低出貨金額）→ 複製文字貼到 LINE → 貨到了按「到貨入庫」核對數量與價格
- **更多**：庫存異動紀錄、廠商與產品（新增廠商、產品、改價格）、費用統整、設定

每一筆庫存變動都會記在試算表的「異動紀錄」分頁（時間、類型、數量、異動後庫存、經手人）。

## 更新價目表

修改 `catalog.js` 即可，格式：`[編號, 系列, 品名, 單價, 分類, 備註, 單位, 廠商]`。
